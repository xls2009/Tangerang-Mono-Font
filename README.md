# Tangerang Mono font
Tangerang Mono is a Thai and Arabic script expansion of Monixend font. Unlike Monixend and Lexend, the Tangerang Mono font uses double-storey “a” instead of single-storey to match with Readex Pro font.
Uniquely, both Readex Pro and Tangerang Mono font uses hook-less/flat/straight-tail lowercase “t” alongside with double-storey lowercase “a”, where this unsual behaviour can only be found in some fonts like Ginto and Satoshi. This is a really rare configuration, and makes the font look more intresting.

Tangerang Mono font is officially licensed under SIL Open Font License 1.1 - You can use this font for developing or experimental purposes.

**Tips:** For a consistency, avoid pairing this font with Lexend font, because Lexend font uses single-storey lowercase “a” winch is matching more to Monixend rather than Tangerang Mono. So, pair the Tangerang Mono font with Readex Pro font instead.

**Fun fact:** Tangerang Mono font is metrically compatible with [Monixend font.](https://github.com/xls2009/Monixend-Font)
