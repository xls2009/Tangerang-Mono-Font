# Tangerang Mono font
Tangerang Mono is a Thai and Arabic script expansion of Monixend font, winch is inspired from Readex Pro font from Google Fonts, completey designed with double-storey “a” instead of single-storey.
Tangerang Mono is a remake/successor of Rexina Mono font, where this remaked version featuring even more glyphs, including Latin, Greek, Cyrillic, Arabic, and Thai scripts.
Tangerang Mono font is officially licensed under SIL Open Font License 1.1 - You can use this font for developing or experimental purposes.

**Fun fact:** Tangerang Mono font is metrically compatible with [Monixend font.](https://github.com/xls2009/Monixend-Font)
